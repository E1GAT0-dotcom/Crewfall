# STATUS — Crewfall (working title)

**Current phase:** Phase 1 — Skeleton (in progress)

## How to launch
Double-click `play.bat` in the project folder. A browser tab opens with the game.
Close the black command window to stop it.

## What works
- Step 1 (tooling): the project builds, tests run, `play.bat` starts the dev server.
- Step 2 (map): `assets/maps/kestrel.json` holds the Kestrel layout (12 rooms, 14 corridors, 2 dead ends,
  4 vent networks, sabotage panels, doors, 18 task spots). The loader in `src/sim/map.ts` reads it,
  builds the walking graph, and `src/sim/mapValidate.ts` checks the SPEC 6.2 rules.
- Step 3 (walking): the ship is drawn from the map file with room labels and the emergency button.
  A cyan placeholder unit spawns in Cafeteria and walks with WASD or arrows at a fixed 30 ticks/s
  with smooth rendering in between. Walls stop it and it slides along them. The camera follows.
  Placeholder sprites are generated by `npm run gen-sprites`.
- Step 4 (HUD): the current room or corridor name shows top-left. Holding Tab shows the whole ship
  with room names and a dot for the player. F3 toggles a debug panel (fps, tick, position, tile,
  room, facing, graph size) and draws the walking graph over the floor. 36 tests pass.
